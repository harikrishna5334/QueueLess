# QueueLess

QueueLess is a portfolio-grade full-stack appointment and live-queue management platform. The primary learning goals are backend Node.js engineering, event-driven architecture, and DevOps, with React included from day one.

## Current status

**Phase 0 - Architecture and Planning.** Approved and complete on 2026-11-04 (including ADR-004 Accepted with Option 1 selected). Phase 1 has not started; Phase 1 implementation is awaiting explicit project-owner authorization.

## How to begin

1. Keep this folder as the dedicated QueueLess project workspace.
2. Open the folder in Antigravity.
3. Review the Phase 0 architecture documents in `docs/architecture/` and `docs/domain/`.
4. Review the Architecture Decision Records in `docs/decisions/`.
5. Require explicit owner authorization before beginning Phase 1 implementation.

## Source of truth

- `AGENTS.md`: primary project constitution and durable AI operating rules.
- `PROJECT_CONTEXT.md`: concise project summary and approved direction.
- `docs/architecture/`: technical specifications, container diagrams, concurrency models.
- `docs/domain/`: domain entity models, ERD, and state transition matrices.
- `docs/decisions/`: approved Architecture Decision Records (ADRs).
- `docs/project-context/current-status.md`: verified current state.
- `docs/tasks/current-task.md`: active task and completion evidence.

Do not treat planned work as implemented. Do not claim tests passed without actual evidence.
