# Model-Independent AI Workflow

1. Read `AGENTS.md`, `PROJECT_CONTEXT.md`, `docs/project-context/current-status.md`, and `docs/tasks/current-task.md`.
2. Read relevant approved architecture/domain documents and ADRs.
3. Restate the task, scope, acceptance criteria, and expected file changes.
4. Propose a plan before implementation.
5. Wait for owner approval for material architecture, security, dependency, scope, or cost changes.
6. Make small, reviewable changes; do not build the entire application in one prompt.
7. Run only authorized, relevant checks and report exact commands and results.
8. Review changes for correctness, security, scope creep, and unnecessary complexity.
9. Update documentation, task status, and handoff.
10. Never claim planned work is implemented or unverified work is tested.
11. Keep all important decisions in repository files; never rely on model memory.
12. End with changed files, verification evidence, unresolved issues, and the next exact step.
